# Inbox

This folder is for passing files back and forth with Claude.

- **To give Claude a file** (a picture for a page, a document to look at), drag or copy it into this folder, then tell Claude it's here.
- **When Claude makes something for you** to look at or keep, it puts it here too.

Nothing in this folder is published, and it isn't saved with the site when you publish. Keep your own copy of anything important somewhere else.
